# Shopify storefront demos

My portfolio site and four concept storefronts that show the kind of result I aim for when I fix or rebuild a Shopify store.

**Live site: https://p-ramcharan-dev.github.io/shopify-storefront-demos/**

| Demo | Line of business | What it shows |
|---|---|---|
| [Marlow Bead Co.](https://p-ramcharan-dev.github.io/shopify-storefront-demos/demos/marlow-bead-co/) | Handmade jewelry | Clean heading outline, shipping and returns on the product page, three-image gallery |
| [Fernhollow Yarn](https://p-ramcharan-dev.github.io/shopify-storefront-demos/demos/fernhollow-yarn/) | Indie-dyed yarn | Consistent spec table, clear shipping times, free-shipping progress in the cart |
| [Patchwork & Pine](https://p-ramcharan-dev.github.io/shopify-storefront-demos/demos/patchwork-and-pine/) | Quilting fabric | Sharp product imagery, pack contents in every listing |
| [Hangar 41 Models](https://p-ramcharan-dev.github.io/shopify-storefront-demos/demos/hangar-41-models/) | Diecast models | Structured specs, dark theme, pre-order terms beside the buy button |

The brands, products and reviews are fictional. These are concept builds, not client work, and nothing can be purchased.

## How it is built

Plain HTML, CSS and about 5 KB of JavaScript, generated by one Node script with no dependencies.

- Every page has one `<h1>`, a meta description, Open Graph tags and a skip link.
- Product pages include `Product` JSON-LD.
- The cart drawer is keyboard-accessible (Escape closes it, focus returns to the button that opened it) and persists in `localStorage`.
- Product art is inline SVG, so pages make no image requests.
- Layout is responsive, with a sticky add-to-cart bar on phones.

```
node build.mjs     # regenerates docs/ from stores.mjs and site.config.json
```

| Path | Purpose |
|---|---|
| `stores.mjs` | Content and colours for each demo store |
| `build.mjs` | Static generator |
| `assets/` | Shared CSS and JavaScript |
| `docs/` | Built site, served by GitHub Pages |
